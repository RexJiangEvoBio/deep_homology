This directory contains data files generated in this study. Code used to generate these files are in the other folders.

# data_effect_all.txt
The C-matrix used in this study. Each column corresponds to a regulator, and each row corresponds to a phenotypic trait. Necessary for all simulations.

# X_ances_diverged
Required for "sim_evo_prior_div.R".

# out_sum_merged.txt
A summary of simulation results obtained under each condition when all lineages had the same ancestral state and the C-matrix did not evolve. Used to produce Figure 1 (each row is a data point in Fig. 1C-D).

# out_sum_merged_pd.txt
A summary of simulation results obtained under each condition when lineages underwent prior divergence and the C-matrix did not evolve. Used to produce Figure 2 (each row is a data point in Fig. 2C-D).

# out_sum_merged_ee.txt
A summary of simulation results obtained under each condition when all lineages had the same ancestral state and the C-matrix did evolve. Used to produce Figure 3 (each row is a data point in the figure).
